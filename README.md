# ملصقات مشكاة — Mishkat Stickers

تطبيق أندرويد من **مشكاة** يضيف ملصقات إسلامية إلى درج ملصقات واتساب، فتصل **ملصقات حقيقية** لا صورًا.

- 68 ملصقًا في 5 حزم: رمضان والصيام · الأعياد والحج · الجمعة · التحية والذكر والدعاء · المناسبات الإسلامية
- زر «أضف إلى واتساب» لكل حزمة (واتساب وواتساب الأعمال)، مع حالة «مضافة ✓»
- مجاني وبلا إعلانات · الموقع: https://mishkatapps.github.io/stickers/

## البنية
| المسار | المحتوى |
|---|---|
| `www/` | واجهة التطبيق (هي نفسها صفحة الموقع) |
| `www/stickers/contents.json` | تعريف الحزم بصيغة واتساب (512×512 WebP ≤ 100KB، أيقونة 96×96 PNG) |
| `native/` | `StickerContentProvider.java` (يقدّم الحزم لواتساب) و`WaStickersPlugin.java` (زر الإضافة) |
| `scripts/wa-native.js` | يضيف المزوّد والإضافة إلى مشروع أندرويد بعد `cap add/sync` |
| `.github/workflows/android.yml` | يبني APK عند نشر إصدار (Release) ويرفقه به |

## إضافة ملصقات جديدة
ضع ملف WebP (512×512، خلفية شفافة، ≤ 100KB) في مجلد الحزمة، وأضفه في `contents.json` و`packs.json`،
ثم **غيّر `image_data_version`** للحزمة (مثلًا من "1" إلى "2") حتى يحدّث واتساب الحزمة عند المستخدمين.
كل حزمة: من 3 إلى 30 ملصقًا. WAStickerApps
