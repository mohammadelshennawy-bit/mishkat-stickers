# ملصقات مشكاة — Mishkat Stickers

تطبيق أندرويد من **مشكاة** يضيف ملصقات إسلامية إلى درج ملصقات واتساب، فتصل **ملصقات حقيقية** لا صورًا.

- 68 ملصقًا في 5 حزم: رمضان والصيام · الأعياد والحج · الجمعة · التحية والذكر والدعاء · المناسبات الإسلامية
- زر «أضف إلى واتساب» لكل حزمة (واتساب وواتساب الأعمال)، مع حالة «مضافة ✓»
- مجاني وبلا إعلانات · الموقع: https://mishkatapps.github.io/stickers/

## البنية
| المسار | المحتوى |
|---|---|
| `www/` | واجهة التطبيق (هي نفسها صفحة الموقع) |
| `www/stickers/contents.json` | تعريف الحزم بصيغة واتساب (512×512 WebP ≤ 100KB، أيقونة 96×96 PNG) |
| `native/` | `StickerContentProvider.java` (يقدّم الحزم لواتساب) و`WaStickersPlugin.java` (زر الإضافة) |
| `scripts/wa-native.js` | يضيف المزوّد والإضافة إلى مشروع أندرويد بعد `cap add/sync` |
| `.github/workflows/android.yml` | يبني APK عند نشر إصدار (Release) ويرفقه به |

## الحزم والتطبيقات (من لوحة مدير مشكاة)
الملصقات والحزم والتطبيقات تُدار من تبويب «🎨 الملصقات» في لوحة المدير، وتُنشر في موقع مشكاة:
`img/stickers/index.json` (الملصقات) و`img/stickers/catalog.json` (الحزم والتطبيقات).

عند البناء (نشر Release أو Run workflow) يقرأ `scripts/build-app.py` الكتالوج ويبني **تطبيقًا مستقلًا لكل تطبيق ملصقات**:
| التطبيق | معرّف أندرويد | ملف التنزيل |
|---|---|---|
| ملصقات مشكاة (أ) | `com.mishkat.stickers` | `mishkat-stickers.apk` |
| ملصقات مشكاة (ب) | `com.mishkat.stickers.b` | `mishkat-stickers-b.apk` |
| ملصقات مشكاة (ج)… | `com.mishkat.stickers.c` | `mishkat-stickers-c.apk` |

كل تطبيق حتى 10 حزم (قيد واتساب)، وكل حزمة من 3 إلى 30 ملصقًا. لا حاجة لتعديل أي ملف في هذا المستودع عند إضافة ملصقات أو حزم:
انشر من لوحة المدير ثم أنشئ إصدارًا جديدًا هنا.
